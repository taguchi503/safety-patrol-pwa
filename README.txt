現場安全巡視 v0.3.6
森建設工業DX「安全管理 ＞ 安全巡視」用PWA。

主な機能
- ○良好 / ×不良 / ／該当なし
- 不良時の巡視者指摘・是正事項（任意入力）
- 音声入力
- 巡視者の写真または電子印鑑
- 点検項目の編集・追加・削除
- 期間コピー（要確認下書き）
- 端末保存 / 保存して次の巡視 / 保存データ
- JSONバックアップ出力・読込
- Excel帳票 / 空白Excel様式 / PDF・印刷


v0.3.4: 不良(×)時の指摘・是正事項を、保存・Excel出力・PDF印刷で必須化。
v0.3.3: 元帳票様式の本物のExcel(.xlsx)出力、空白Excel、音声入力末尾句読点除去に対応。


v0.3.5: ×不良でも是正欄は任意入力。保存・Excel・PDFを空欄のまま実行可能。アプリ内に変更履歴を追加。

v0.3.6: スマホ縦画面の巡視結果を1項目1カード表示に変更。横スクロールなしで○/×/該当なしを選択可能。
