現場安全巡視 v0.3.12（内部キャッシュ v0.3.12-r1）

ZIPを解凍して、既存のGitHubリポジトリ safety-patrol-pwa の同じ階層へ上書きしてください。
別リポジトリへの移行やURL変更は不要です。既存ファイルは手動で削除しないでください。

【画像キャッシュ更新】
旧版キャッシュから削除する対象はアプリ構成画像3枚のみです。
  guide-quick.png / guide-detail.png / icon.svg
同じ画像URLのクエリ付き旧キャッシュも削除します。
他の画像（利用者が保存した写真等）、非画像キャッシュ、他アプリのキャッシュは削除しません。
最新版一式を取得できてから更新を有効化します。取得に失敗した場合は旧版を維持します。
保存データのキー・形式は変更しません。サイトデータの削除や再インストールは行わないでください。
通信できる状態でアプリを開き、更新取得後に入力内容を保存して開き直してください。
画面を強制再読み込みする処理はありません。必要に応じて既存のJSONバックアップ機能をご利用ください。
ホーム画面のアイコン画像はOS側が独自に保持する場合があります。

【PDF・印刷の変更】
通常30項目の点検表をA4縦1ページのPDF実ファイルとして生成します。長い指摘事項や備考は可読性を保つため続紙に出る場合があります。
個別・一括とも同じPDF方式です。iPhone/iPadでは「PDFを共有・印刷」から共有画面の「プリント」を選択します。その他の端末ではPDFを開いて印刷します。
印刷設定はA4縦を指定してください。端末・プリンターが対応している必要があります。

【v0.3.12 の変更】
PDFの巡視員名横の印欄を廃止。右側の安全巡視員欄の電子印鑑・写真はそのままです。元Excel様式は変更していません。
写真モードで「写真を撮る」と「写真を選ぶ」を使い分けてください。撮影では前面カメラを指定していますが、カメラ起動・選択画面はOSとブラウザの対応状況に依存します。
